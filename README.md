# MimiBoot-Mu docs

Documentation for [MimiBoot-Mu](https://github.com/MilkmanAbi/MimiBoot-Mu), published at
https://milkmaidabi.github.io/MimiBoot-Mu-Docs/

It's a plain Jekyll site built by GitHub Pages: Markdown pages in the root, one layout in
`_layouts/`, one stylesheet in `assets/`. `options.md` and `boards.md` are generated from
the MimiBoot-Mu repository's `config/features.toml` and `config/targets.toml`.
